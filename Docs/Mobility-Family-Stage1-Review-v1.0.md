## Section 3 — Family-Level Questions

**A — Did both programs survive governance?** **Yes — both APPROVE.** Zero retirements.

**B — Is the convergence pair resolved?** **Yes.** Mobility Foundation ↔ Mobility Intermediate is the catalog's leanest pair (level + duration only). Mobility Foundation established the baseline and a three-part falsifiable test (Foundation §9); Mobility Intermediate **passed all three** (Intermediate §8): (1) **more challenging variations** — the §11.8 intermediate lever (deeper positions / harder poses / more complex flows) that Foundation deliberately withholds; (2) **meaningfully deeper / longer holds** — greater ROM and longer durations, not the same holds for two more weeks; (3) **non-derivability** — distinguishable with level/duration hidden, by content depth and target athlete. No unresolved pair remains.

**C — Is the Foundation → Intermediate distinction coherent?** **Yes** — across three axes (Section 4): a **distinct athlete** (new-to-mobility vs experienced practitioner / Foundation graduate), **distinct content** (the §11.8 harder-variation lever withheld at Foundation, activated at Intermediate, plus deeper/longer holds), and a **distinct role** (on-ramp to the practice vs its deepened terminal endpoint). The shape is shared; the content is not.

**D — Any retire/revise candidates?** **None.** Neither program rests on topology — the §11.8 content progression is genuine. Structurally the family is at the **2-program minimum** (PEA §2.1); retiring either rung would drop it below the floor (the Running 2-program logic). Mobility Intermediate is the **watch program** — the leanest-justified in the catalog — not a retirement candidate (Section 5).

**E — Any journey-gap findings?** **None.** Mobility Intermediate is **terminal complete-by-design**: there is no Mobility Advanced in the catalog or on the PEA §7.1 roadmap, and none is warranted — mobility is a continuous supportive practice and an INTERMEDIATE rung is a complete, sensible endpoint. This is a clean terminus, distinct from the terminal-by-unbuilt-successor gaps elsewhere (Running Base II, Lower Body Intermediate, Home Strength Foundation).

**F — Ready for Stage 2?** **Stage-2 governance-ready** — the governance bar is met. The standard cross-family preconditions still apply (Exercise Library population — the nine MOBILITY anchors are already content-authored in `Anchor-Exercise-Population-Pass-03-v1.0.md`, pending review/media; and the pre-publish PAS-R1 audit), and the single content-depth watch item (Section 5) must be honored. It becomes a *fixed* Stage 2 input only when the product team **LOCKs** the Stage 1 artifacts — not implied by this review.

## Section 4 — Foundation → Intermediate Distinction

| Axis | Mobility Foundation (Sort 23) | Mobility Intermediate (Sort 24) |
|---|---|---|
| **Target athlete** | New to structured mobility (no assumed technique) | Experienced practitioner / Foundation graduate (familiar with patterns) |
| **Variation difficulty** | Foundational, accessible, basic holds | Deeper positions, harder poses, more complex flows (§11.8 lever) |
| **Hold depth / duration** | Foundational ranges; duration-only progression on a basic set | Greater ROM demand; meaningfully longer holds, progressing further |
| **Progression dimensions used** | §11.8 (a) longer holds only | §11.8 (a) longer holds **+ (b) more challenging variations** |
| **Role** | On-ramp to the practice | Deepened, terminal endpoint of the practice |

**Deliberately shared (the leanness):** goal (IMPROVE_MOBILITY), environment (HOME), frequency (5/wk), athlete type (All), progression model (Time-Based / Model 5), deload (none), MAIN-only structure. The distinction is genuine but rests **entirely on authored content depth and target-athlete experience** — the thinnest metadata separation in the 24-program catalog, justified by PAS §11.8's explicit definition of intermediate mobility programs as harder *content*, not merely more weeks.

## Section 5 — Watch Items & Stage 2 Caveats (carried forward)

1. **Content-depth dependency (load-bearing — the family's sole watch item).** Because the pair's metadata separation is the leanest in the catalog (level + duration only), **authored content is the only axis carrying the Foundation ↔ Intermediate distinction.** Stage 2 **must** author Mobility Intermediate with genuinely harder variations (deeper positions / harder poses / more complex flows) **and** meaningfully deeper/longer holds. If it is authored as Mobility Foundation's holds prescribed for two more weeks, the pair collapses into catalog topology → re-differentiate (deeper Intermediate content). **Retirement is not available** as a remedy — the family sits at the 2-program minimum (PEA §2.1), so a failure points to re-differentiation, not removal. This is the family's single most important Stage 2 instruction, and the catalog's hardest "is the second rung real?" case to keep honest in implementation.
