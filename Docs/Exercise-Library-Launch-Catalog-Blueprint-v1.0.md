**Purpose:** Define exactly which exercises belong in the launch catalog — name, category, movement pattern, equipment tag(s), and anchor status only — before any exercise content authoring begins.

---

## Section 1 — Catalog Size Validation

**Recommended launch count: 200**, unchanged from the locked Production Plan. Rationale carries forward verbatim from that plan: "200 complete exercises is preferable to 500 at partial quality." This blueprint adds one new confirming data point: the mandatory-inclusion set (every Program-Authoring-Standard-named compound, every architecture-named anchor example, and every exercise name already used in the three readable committed Strength Foundation packages) totals **46 distinct names**, comfortably inside a 200-row budget with room remaining for full category, pattern, and equipment coverage.

**Minimum viable count: 188** — the sum of all six locked category floors (55+40+30+28+20+15). Below this, at least one category falls under its architecture-mandated minimum.

**Maximum recommended count: 225** — the sum of all six locked category ceilings (65+50+35+32+25+18). Above this, the Production Plan's own "overflow capacity" framing is exceeded; the architecture treats 201–225 as headroom for naturally wide categories (Legs & Glutes, Mobility), not a second target.

**This blueprint's catalog: exactly 200**, distributed at the midpoint of each locked range (see Section 2), satisfying the content-team target precisely rather than drifting toward either bound.
