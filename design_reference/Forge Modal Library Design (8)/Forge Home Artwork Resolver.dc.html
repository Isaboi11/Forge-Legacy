Master Artwork Reference · Systems · Specification

HOME WORKOUT
ARTWORK RESOLVER

Deterministic · centralized · testable · reusable

The single source of truth for choosing the artwork on the Home “Today’s Workout / Start Workout” card. One resolver decides which illustration describes today’s workout — not merely the program — from structured data, falling back through a fixed precedence to a guaranteed neutral default. The Home card contains no classification logic; it receives only the resolved artwork object.

§ 01 · Resolution Precedence

Seven rungs, top to bottom.

The resolver walks the ladder in order and returns the first rung that produces a valid, registered key. Every rung fails safe: an invalid or empty result falls through to the next. The ladder always terminates at a registered neutral default, so the card can never be blank or broken.

§ 03 · Sex Variant

Resolved from saved selection only.

The artwork set is chosen strictly from the user’s explicit saved sex. It is never inferred from name, profile photo, training behaviour, body weight, or any other attribute.

§ 05 · Asset Manifest & Naming

Registered keys, never built strings.

The resolver returns a key; a registered manifest maps that key to a file. Filenames are never constructed dynamically at the call site. Every supported key must validate against the manifest before it is returned — an unregistered key is treated as a miss and falls through.
