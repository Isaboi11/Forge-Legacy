Section 02 · Modal (CLA-C20)

Ceremony Modal

The only centered-modal class — reserved for earned moments (M-1–M-9). No tap-outside dismiss; the athlete must act. The celebration mark is an Insignia artwork slot (bespoke badge art mounts here), never a generic icon, and the copy is the locked ceremony line.

Section 03 · BottomSheet (CLA-C21)

Bottom Sheets · the utility surface

Everything that is not a ceremony is a bottom sheet: confirmations, forms, action menus, pickers, filters, set input. Slides up, drag handle, tap-outside dismiss by default. Destructive confirmations require an explicit choice.

Section 04 · Toast (CLA-C22)

Toast

Transient and non-modal — it marks something that already succeeded, then auto-dismisses after 3 seconds (announced via aria-live="polite"). Positive or neutral only; failures are native alerts, never a toast.

Show toast “Chapter I has started.” · 3s auto-dismiss
Section 05 · Skeleton (CLA-C23)

Loading & Skeletons

Skeleton placeholders are the default wait state — they hold the layout and are suppressed under 200ms. A blocking loading modal is the rare exception, only for user-initiated waits with no partial UI to show. Under Reduce Motion the shimmer becomes a static block.

Blocking overlay is the exception — a fixed panel whose indicator swaps between loading, success and failure in place. Never a fake progress bar; a determinate bar only when progress is truly measurable.
Section 06

Error Handling

There is no custom error modal. Account-level failures (sign-in lockout, session expiry, delete) use the platform’s native alert. In-context, recoverable failures resolve inline — a quiet muted-red edge on the field, never an alarming fill.
